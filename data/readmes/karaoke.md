# Karaoke Booth

Live voice booth with WASAPI effects.

## Overview

Amplify your mic, autotune, and add character effects — alien, chipmunk, demon, robot, telephone, chorus, radio — plus reverb and echo. Native Windows audio for lower latency; Discord via Stereo Mix. Browser demo included.

## Tech / Stack

- Rust
- WASAPI
- egui
- TypeScript
- Vite
