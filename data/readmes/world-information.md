# World Information

Public data, told as lives. Official World Bank and UNHCR series, with the year and a source on every number. Missing figures are shown as gaps, not zeros.

**Live:** [pfaustino.github.io/world-information](https://pfaustino.github.io/world-information/)

## Local

```bash
npm install
npm run dev
```

Refresh the snapshot from the public APIs with `npm run data`. City photos are Wikimedia Commons files in `public/photos/` (`npm run photos`).
